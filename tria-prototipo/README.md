# TRIA — protótipo navegável

Protótipo (não é o sistema completo) da aplicação de organização de trabalhos em grupo.
Feito só com HTML, CSS e JavaScript: **abra `index.html` no navegador**, sem instalar nada.

Telas: Visão geral · Meus grupos (e detalhe de cada grupo) · Todas as tarefas (filtros por status) · Painel do professor.

O que funciona: criar conta e entrar (aluno ou professor), criar/concluir/excluir tarefa, filtros, busca (Enter),
criar grupo, gerenciar membros, ritmo da semana, recado e lembrete do professor para o grupo.
As contas ficam salvas no navegador. Grupos e tarefas são dados de exemplo e voltam ao início ao recarregar.

`overleaf/desenvolvimento.tex` — texto da seção "Desenvolvimento" do artigo (modelo SBC).
